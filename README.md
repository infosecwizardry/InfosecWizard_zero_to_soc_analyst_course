# Zero to Hero: The 8-Week SOC Analyst Foundation

A free, hands-on path from absolute beginner to job-ready SOC analyst, built around a weekly YouTube series. No paywalls, no fluff, no prior experience required.

This repository holds everything that supports the video course: lesson notes, lab walkthroughs, cheat sheets, sample logs, and curated resources. New content drops every week as new episodes go live.

## 📅 The 8-Week Roadmap

| Section | Topic | What You'll Be Able to Do |
|------|-------|---------------------------|
| 1 | SIEM Fundamentals | Navigate, search, and pivot through a SIEM with confidence |
| 2 | Windows Logs | Read and triage Windows event logs like a native language |
| 3 | Phishing & Attack Chains | Investigate phishing end-to-end and map the attack chain |
| 4 | Authentication Attacks | Spot Kerberos abuse, AD attacks, and brute force attempts |
| 5 | Malicious PowerShell | Decode and analyze obfuscated malicious PowerShell |
| 6 | Network Logs | Hunt C2, exfil, and threats in firewall and WAF traffic |
| 7 | Detection Logic | Read existing detections and write your own |
| 8 | Capstone Investigation | Run a full investigation and deliver a written report |

## 🧙 How to Use This Repo

Each section has its own folder following the same structure:

- `README.md`: lesson notes, video link, learning objectives, key takeaways
- `lab.md`: hands-on exercise with step-by-step instructions
- `resources.md`: links, further reading, referenced tools
- `assets/`: diagrams, sample logs, screenshots, exports

If you're brand new, start with `00-start-here/` and work straight through Section 1. If you're brushing up on a specific topic, jump to the section you need.

## 🛠 Before You Start

Head to `00-start-here/prerequisites.md` and `00-start-here/lab-setup.md` for the short list of free accounts and tools you'll need. Plan for about an hour to get your lab environment ready before Section 1.
