# Zero to Hero: Cybersecurity Course

Welcome to the official companion repository for the InfosecWizard Zero to Hero course. This is a free, hands-on path from absolute beginner to job-ready in cybersecurity, built around a weekly YouTube series.

This repo holds all the supporting materials for the playlist: lesson notes, lab walkthroughs, cheat sheets, command references, and curated resource links. New content is added every week as new episodes drop.

If you're brand new to cyber, start with Episode 1 and work through the materials in order. If you're brushing up on a specific topic, jump straight to the folder you need.
